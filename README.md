# AI Audio Summarizer 🎙️

An advanced audio processing pipeline that transcribes, analyzes, and summarizes audio content using AI.

## Features ✨

- 🎧 **Audio Transcription** using OpenAI Whisper
- 🗣️ **Multi-speaker Diarization** for conversations
- 📊 **Emotion Analysis** of speech content
- 📋 **Dual Summarization** (abstractive & extractive)
- 📈 **Visual Analytics** with multiple plot types
- 🎯 **Keyword & Task Extraction**
- 📖 **Chapter Generation** with timestamps
- 📄 **Comprehensive Reports** in multiple formats
